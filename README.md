# IELTS_AI
This is my work towards developing an LLM to the goal of grading and evaluating IELTS writing tests for students. It may be used int he future for the IETLS test portal. This is to improve my AI skills and also help me practice my React frontend skills.

## Wireframe
[Dark Mode Text Input Area (Figma)](https://www.figma.com/make/X1LMXxW07BDVgK6QuaVGV5/Dark-Mode-Text-Input-Area?t=S5LenW7GHt9945NF-1)

The wireframe contains the input design, submission button design, timer and initial message. Also the animation for when you press submit.
